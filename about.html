About Jinnie Chat

Jinnie Chat is a lightweight, privacy-first real-time chat platform focused on simplicity, security, and an ultra-tactile Claymorphism user experience across devices.

Mission

Our mission is to provide a fast, private, and frictionless chat solution that requires zero tedious signups. Users can create password-protected rooms, invite friends via shareable links or SMS, and exchange instant messages and files in real-time with complete peace of mind.

Core Capabilities

  • Password-Protected Rooms: Fine-grained room access control guarded by creator passwords.
  • Low-Latency Realtime: Lightning-fast bidirectional WebSocket communication.
  • Rich Media Sharing: Inline image rendering and document transfers.
  • Claymorphism Design System: Soft, inflated dimensional surfaces with light highlights and ambient depths.
  • PWA & Mobile Ready: Responsive layout optimized for smartphones, tablets, and desktops.

Security & Privacy

We believe in strict data minimization. Users don't need to provide phone numbers or personal identifiers to start conversing. For self-hosted and independent instances, administrators have complete control over retention and ephemeral message cleanup.
